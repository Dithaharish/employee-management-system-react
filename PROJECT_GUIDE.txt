1. WHAT IS THIS PROJECT?
========================================================================

It is an Employee Management System (internal company portal) called
"PeopleDesk". It is a website that has two types of users:

  - ADMIN  (HR / management)
      Can view the dashboard, see all employees, add new employees,
      edit employee details, manage departments, and update their own
      profile and password.

  - EMPLOYEE (staff)
      Can view their own dashboard, view/complete their profile, and
      change their own password.

TECHNOLOGY USED
  - React 18          - the JavaScript library used to build the screens
  - React Router DOM  - handles page navigation (URLs)
  - Vite 5            - the development tool that runs the project and
                        bundles it for production
  - JavaScript (JSX)  - the programming language used
  - HTML / CSS        - page structure and styling
  - localStorage      - browser storage used to save all data
                        (no database or server needed)

IMPORTANT NOTE ABOUT DATA
  All data is stored inside the web browser's localStorage. This means:
    - There is NO backend server and NO database.
    - Data saved by one person is visible ONLY in that browser and
      computer. It is not shared between different users/computers.
    - If you clear browser data (cache/cookies/site data), all saved
      changes are lost and the app resets to the built-in sample data.

4. HOW TO RUN THE PROJECT (step by step)
========================================================================

STEP 1: Open a terminal
    - Windows: Press Win + R, type "cmd", press Enter.
      (or search "Command Prompt" in the Start menu)

STEP 2: Go to the project folder
    Type the following and press Enter:
        cd C:\Users\SK\employee-management-system-react
    (Use the path where the project actually is on your computer.)

STEP 3: Install the project files (ONLY the first time)
    Type:
        npm install
    This reads package.json and downloads all required libraries
    into the "node_modules" folder. It may take 1-5 minutes.
    You only do this once per computer.
    (If the folder already contains node_modules, you can skip this.)

STEP 4: Start the development server
    Type:
        npm run dev
    You will see output similar to:
        VITE v5.4.21  ready in 976 ms
        Local:   http://localhost:5173/

STEP 5: Open the app in your browser
    Go to:  http://localhost:5173
    The login page will appear.

STEP 6: Stop the server (when you are done)
    Click on the terminal window and press:  Ctrl + C
    Then press "Y" and Enter if asked to confirm.

NOTE ABOUT PORTS:
    Port 5173 is the default. If it is already in use, Vite will
    automatically pick 5174, 5175, etc. - always use the exact
    link shown in your terminal.

WINDOWS POWERSHELL USERS - IMPORTANT:
    If you use PowerShell (not Command Prompt) and see this error:
        "npm.ps1 cannot be loaded because running scripts is
         disabled on this system"
    You have two easy fixes:
      Fix 1 (recommended): Use Command Prompt (cmd) instead.
      Fix 2: In the PowerShell command, use "npm.cmd" instead of
             "npm" - for example:  npm.cmd run dev

7. FEATURES EXPLAINED (what you can do in the app)
========================================================================

ADMIN FEATURES
  - Dashboard: shows total number of employees and departments,
    a search box, and the employee list.
  - Employees: view the full employee list and search by name.
  - Add Employee: register a new employee (name, email, phone,
    department, designation, joining date, address, emergency
    contact, etc.).
  - Edit Employee: update the details of an existing employee.
  - Departments: view, search and manage departments
    (name, manager, status).
  - Add Department: create a new department.
  - Admin Profile: view/update the admin's own profile.
  - Change Password: change the admin login password.

EMPLOYEE FEATURES
  - Dashboard: personal overview page.
  - Profile: view and complete personal profile details
    (date of birth, blood group, address, city, state, postal code,
    emergency contact, etc.).
  - Complete Profile: shown for first-time login so the employee
    can fill in missing details.
  - Change Password: change the employee's own password.

9. HOW DATA IS SAVED (important for everyone)
========================================================================

  - The app has NO database and NO backend server.
  - Everything is saved in the browser using localStorage:
        employees, departments, admin profile, passwords.
  - The files employees.json and departments.json contain the
    starting/sample data. Any change made in the app is stored in
    the browser and layered on top of that sample data.
  - Consequences to remember:
        * Different browsers/computers do NOT share data.
        * Clearing browser site data resets everything to the
          sample data.
        * Refreshing the page does NOT lose data.

11. TROUBLESHOOTING (common problems and fixes)
========================================================================

Problem: "npm is not recognized" / "'npm' is not recognized"
  Cause: Node.js is not installed or the terminal was not restarted
         after installing Node.js.
  Fix:   Install Node.js from https://nodejs.org (LTS), then close
         the terminal, open it again, and try again.

Problem: "npm.ps1 cannot be loaded because running scripts is
         disabled on this system" (PowerShell only)
  Fix 1: Use Command Prompt (cmd) instead of PowerShell.
  Fix 2: Type npm.cmd instead of npm (example: npm.cmd run dev).

Problem: Port 5173 is in use
  This is NOT an error - Vite automatically uses the next free port
  (5174, 5175, ...). Just open the link shown in the terminal.

Problem: Page shows a blank white screen
  Fix:   - Make sure you opened the link from the terminal output.
         - Clear the browser cache / hard refresh (Ctrl + Shift + R).
         - Check the terminal for error messages.

Problem: "Invalid email or password" on the login page
  Fix:   Use the exact credentials from Section 5 of this document.
         Admin uses admin@company.com / admin123.
         Employees use their email and employee123 (or the password
         set for them).

Problem: All data disappeared / app looks reset
  Cause: Browser site data (localStorage) was cleared.
  Note:  This is expected behaviour - there is no server database.
         Data must be re-entered or the page simply refreshed
         without clearing site data.

Problem: Changes in code are not showing in the browser
  Fix:   The dev server has hot reload - save the file and the
         browser updates automatically. If not, refresh the page.

13. FREQUENTLY ASKED QUESTIONS (FAQ)
========================================================================

Q: Do we need internet to run this?
A: No. Once the libraries are installed (npm install), the app runs
   completely offline on your computer.

Q: Is this app deployed online?
A: Not by default. It runs locally. To share it with others it must
   be built (npm run build) and hosted on a server, which needs a
   separate decision from the team.

Q: Can we connect a real database later?
A: Yes, but that requires adding a backend (e.g. Node/Express,
   Spring, etc.). The current version is frontend-only and stores
   data in localStorage.

Q: Where do I see errors if something breaks?
A: In the terminal where you ran "npm run dev" (server errors) and
   in the browser's Developer Tools console (F12 -> Console tab).

Q: Who do I contact for help?
A: Contact the developer who set up this machine / the project
   administrator. For password resets inside the demo data, use the
   admin login.
